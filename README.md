# Piscis Propostas, piloto fictício

Página de teste do piloto do CRM Piscis. Todos os dados são fictícios (códigos FIC).
Nenhum dado real de cliente, nenhum envio real.

- `index.html`: página única com a visão do consultor de teste e a visão do cliente de teste (aberta por link com token).
- Backend: projeto Supabase de teste (plano gratuito), acessado apenas com a chave publishable, que é pública por desenho.
- Publicação: GitHub Pages neste repositório.
